# Синтетические данные для Data-Driven Curriculum

Все данные синтетические: реальных людей, школ и результатов здесь нет.

## Что внутри
- `code/generate_data.py` — генератор (алгебра 7 класс, 60 школ, 120 классов, ~3 100 учеников, 12 тем, 86 заданий, ~260 тыс. ответов). Параметры «истины» в блоке ПАРАМЕТРЫ ИСТИНЫ в начале файла.
- `code/analyze.py` — наивное сравнение против модели с поправкой + валидация по истине.
- `data/` — файлы в схеме из отчёта: `results_long.csv` (одна строка = ученик × задание), а также нормализованные `results.csv`, `items.csv`, `students.csv`, `schools.csv`, `teaching.csv`, `hours.csv`.
- `data/ground_truth.json` — заложенная истина. Аналитический код (часть 1) её не читает, её читает только блок валидации.
- `report.md` — результат запуска на seed 2026.

## Запуск
```
pip install numpy pandas scipy statsmodels
python3 code/generate_data.py --seed 2026 --out data
python3 -I code/analyze.py --data data --out report.md
```

## Заложенные сценарии
1. Парадокс Симпсона: учебник A стоит в основном в сильных школах, поэтому его средний балл выше, а истинный эффект отрицательный (−0,30 логита).
2. У A дополнительная слабость на «Функции и графики», у C дополнительная сила на «Системы линейных уравнений».
3. Разная сложность тем; часы влияют на результат с убывающей отдачей (логарифм), на трудных темах сильнее.

## Ограничения (важно для питча)
- Это проверка метода на симуляции при известных допущениях, а не доказательство работы в реальных школах.
- Данные сгенерированы моделью IRT, и анализ использует ту же логику, поэтому результаты оптимистичны по сравнению с реальностью.
- Часы в данных назначены случайно (±25% от базы). В реальных школах трудным темам дают больше часов, и это даёт обратную причинность.
- Если в школе мало школ на учебник (в выборке B в elite: 1 школа), оценки внутри типа школы шумные.
